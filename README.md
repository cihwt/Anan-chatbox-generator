# 安安的素描本聊天框 · 网页版

[![License](https://img.shields.io/badge/license-MIT-blue)](#许可证)
[![Dependencies](https://img.shields.io/badge/dependencies-none-brightgreen)](#功能特点)
[![Platform](https://img.shields.io/badge/platform-any%20modern%20browser-lightgrey)](#系统要求)

输入文字并配好图片后，可将其绘制到素描本风格图片的指定区域，获得与游戏内相近的观感。

本项目是其**网页版**实现，功能同样是「把文字与图片贴到画面上」，但完全以 HTML/CSS/JS 编写：**无需安装、无第三方依赖、打开即用**。原版为 Python 桌面程序，部署与运行相对繁重；网页版更轻量，也便于嵌入 WebView（例如后续可打包为 Android 应用）。

> 独立制作的同人工具（作者：inswth），与原作者及游戏官方无关联。默认素材来源见 [许可证](#许可证)。

## 功能特点

- 🪶 **轻量**：纯前端实现，无第三方依赖、无需构建，打开 `index.html` 即可使用
- 🖼️ **灵活**：可自由更换背景图，并在图上自由框选绘制区域
- ✨ **图片叠加**：可为每个模板叠加一张图片，保持原图尺寸，位置可拖动调整
- 🔤 **自适应字号**：只需设定最大字号，文字超出时会自动缩小以适配区域
- 🎨 **填充样式**：纯色、取色器自定义、双色渐变
- 🗂️ **多模板管理**：支持在本地保存、复制、编辑与删除，数量不限
- 📦 **导入导出**：模板可一键打包为 zip，便于备份与分享
- 📋 **一键复制 / 下载**：生成结果可复制到剪贴板或下载为 PNG/SVG
- 📱 **易嵌入**：仅为单个文件夹、无构建步骤，便于嵌入 Android WebView

## 系统要求

- 任意现代浏览器（Chrome / Edge / Firefox 等）
- 无需安装任何运行环境，用浏览器直接打开即可（亦支持以 `file://` 方式从本地打开）

## 使用方法

`web/` 目录包含全部网站文件，用浏览器打开其中的 `index.html` 即可。

> 首次运行会自动载入随附的默认模板，可直接开始使用。

### 生成

1. 选择一个模板。
2. 输入文字（`#文字#` 会变成紫色）。
3. 调整「最大字号」与「填充」（纯色 / 渐变）。
4. 点击 **复制图片** 复制到剪贴板，再粘贴到聊天软件中发送；或点击 **下载图片** 保存为 PNG。
5. 若临时调整了区域，点击「覆写模板」将改动保存回该模板。

### 添加模板

1. 点击模板选择中的「＋ 添加模板」，上传一张背景图（图片＋号图标）。
2. 拖动四个角的圆点，圈定要绘制的区域；如有需要，可用旋转 / 水平镜像 / 垂直镜像调整方向。
3. 可选：点击「叠加图片」（图层图标）添加一张叠加图，拖动以调整位置（保持原图尺寸，无需缩放）。
4. 填写模板名称，点击「保存模板」。

### 模板管理

- 模板选择弹窗顶部提供一排按钮：**全选**、**导入 ZIP**、**导出 ZIP**、**删除所选**。
- 每张模板卡片右侧提供 **复制 / 编辑 / 删除**。
- 导入与导出所用的 zip 内含 `manifest.json` 与 `images/`，记录每张图片与模板的对应关系。

## 配置参数

所有参数均在界面中设置，无需编辑配置文件，并自动保存在浏览器本地：

- 背景图、绘制区域四角坐标
- 叠加图及其位置
- 模板名称、最大字号、填充样式
- 模板列表与图片资源

## 项目结构

```
.
├─ README.md / LICENSE / NOTICE.md
└─ web/                      # 网站本体，部署此目录即可
   ├─ index.html             # 页面与全部交互逻辑
   ├─ app.css                # 样式
   ├─ overlay.js             # SVG 区域/控制点渲染
   ├─ store.js               # 模板与图片存储（IndexedDB / localStorage）
   ├─ zip.js                 # 极简 ZIP 读写（无依赖）
   ├─ defaults.js            # 首次运行的默认模板（内含 exported-templates.zip 的 base64）
   └─ exported-templates.zip # 默认模板源文件
```

`web/` 为纯静态文件，可直接部署到任意静态托管（例如 GitHub Pages，发布目录选择 `web/`）。

## 与原项目的差异

网页版定位为**更轻量、更灵活**，绝大多数需求均可直接在界面中完成：

- **跨平台**：无系统限制，现代浏览器通常都能运行，也便于嵌入移动端。
- **自定义图片与区域**：原版底图与绘制区域均需在配置文件中设定；本版可任意上传背景图，并通过拖拽四个角点圈定任意四边形区域。
- **多模板与图片叠加**：原版一次仅一张图、一套配置；本版可保存多个模板，且每个模板可单独配置一张叠加图。
- **导入导出**：模板可打包以便分享。
- 暂不支持、且**无计划**支持的功能：全局热键、表情标签（如 `#普通#`）自动切换。

## 常见问题

1. **打开后页面空白或图片无法读取？** 建议使用 Chromium 内核浏览器（Chrome / Edge）；以 `file://` 打开时，个别浏览器会限制对本地文件的读写。
2. **模板会丢失吗？** 模板保存在浏览器中，清除浏览器缓存或站点数据时可能一并被删除。建议定期使用「导出 ZIP」备份，更换设备后再以「导入 ZIP」恢复。
